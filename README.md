# Hussnain Shabir Portfolio

An original responsive portfolio starter built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and editable content
- `style.css` — layout, dark/light theme styles, mobile responsiveness
- `script.js` — mobile navigation, theme switch, scroll reveal, and email-form draft

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` and `script.js` with your real email.
2. Replace generic social profile links with your real profile URLs.
3. Review all experience and project descriptions; publish only details and results that are accurate and approved.
4. Open `index.html` locally to test.

## Deploy on Vercel
Import the GitHub repository into Vercel. For this static site, use the project root as the root directory; no build command is required and the output directory can be left empty/default.
